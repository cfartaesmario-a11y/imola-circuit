# Imola Test

Prueba del circuito de Imola en 3D con un coche básico para detectar fallos en el modelo (agujeros, zonas sin suelo, rendimiento).

**Controles:** WASD o flechas para conducir · Shift turbo · R reset · C cámara libre

## Crédito del modelo 3D
